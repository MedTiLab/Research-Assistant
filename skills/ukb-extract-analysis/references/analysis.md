# easyUKB 分析衔接

从原 easyukb-analysis 整合函数手册和函数索引，支持表型构建、暴露/协变量/结局、衍生指标和关联模型。函数手册来自原 skill 的源码注释快照，保留 218 个定义；可能含同名内部函数、历史默认值或示例错误。不要仅根据函数名生成参数。

## 调用验证

先在 `easyukb-function-index.csv` 找函数，再用 `rg -n '^### 函数名$' easyukb-functions.md` 定位完整签名。若本地装有 easyUKB，再检查导出和 `formals(getExportedValue("easyUKB", "函数名"))`。原包曾有加载时联网激活逻辑，当前环境未验证该行为；本 skill 的提取和 codebook 查询不依赖它。

常用入口：`set_data_path(path)`、`Common_data_extraction(path = NULL, id, name)`、`batch_merge_data_optimized(data_path = NULL, id_list)`。调用前确认用户路径和字段存在性；`name` 与 `id` 长度必须相等。函数返回后验证所有请求字段、eid 唯一性与参与者覆盖，没有验证前不要声称提取成功。

## 从提取到分析

用户只要求“提取变量并给出统计建议”时，交付建议即可，不默认执行模型，也不要求安装 easyUKB。先按 [官网核对流程](official-verification.md) 确认所用变量的语义；官网不可达则用本地并标记来源。

建议应说明：暴露、结局、协变量各自的候选字段与时间点；适合研究目标的主模型及理由；候选混杂因素的纳入依据；缺失和特殊编码处理；关键假设、诊断及敏感性分析。模型选择需要结合结局类型、随访和重复测量结构，不能仅根据字段存储为数值就当成连续变量。没有真实数据时，将缺失比例、事件数、分布和模型假设检查列为提取后待确认，不生成估计结果。默认 20 行是按 eid 排序的预览，不据此估计全队列分布或制定最终缺失处理方案。

1. 明确研究人群、暴露、结局、时间零点、随访截止来源、排除条件与估计目标。
2. 从已确认的列和 codebook 构建变量。保留原始列，派生列记录单位换算、特殊编码、阈值、测量实例和缺失规则。
3. 按需要查询 `calculate_*`、`time_Extract`、`First_occurrences_*`、`Hospital_*`、`p2000*` 等函数族。SPISE、MetS、eGFR、PhenoAge 等各有不同输入单位和人群适用条件，核对手册参数和研究来源，不能相互替代。
4. 根据研究问题决定模型。Cox 需要明确事件和随访时间并评估比例风险假设；logistic 用于相应二分类估计；RCS 需说明节点与参考点；多状态需定义合法转换；中介分析需交代假设。输出估计值、区间、样本/事件数、缺失处理和必要的敏感性分析。

协变量根据混杂结构和研究设计确定，不强制原 SPISE-CMM 示例的固定 M2 列表。标准化、分位数组和多重检验处理按研究目标选择，不自动运行全部模型。

## 结局与时间

候选来源包括算法定义、First occurrences、住院诊断、死亡登记、自报等。先核查疾病特异的字段定义和各来源覆盖，再确定主分析与敏感性分析。多个来源并非独立证据，不能把所有疾病都强制四源取并集，也不套用“漏诊 30–40%”等未经当前研究核验的比例。

ICD 编码是否去点号、匹配完整代码还是前缀，应与 codebook 和研究定义一致，保留原值。诊断与日期通过相同实例和 array 关联。阴性、未知与没有记录应区分；不能因没有日期就制造阴性诊断。

随访终止时间由研究方案规定的有效截止组成，不沿用手册的历史固定默认日。需特别处理：全缺失组上 `pmin(..., na.rm=TRUE)` 的 Inf、全缺失 `pmax` 的 -Inf、Date 类型转换、事件早于基线、事件晚于截止和不同地区数据覆盖截止不一致。

手册的 `time_Extract`、`combine_diseases_and_*` 和糖尿病综合函数可作为实现候选，不能替代研究定义或强制用于所有问题。

## 已修正的继承问题

- 字段查询无需先索取原始路径。
- 使用大写 `ID`；缺请求列即失败，不静默跳过。
- 按本地字典实际展开数组，保留两种命名体系，测量实例不默认套成基线。
- 不强制固定协变量、固定随访截止、多源优先级或分析模型。
- 不把旧函数手册宣称为当前已安装版本；对不存在/未导出的函数明确报出限制。
